# Bachelet PM — Électroménager à Créances

Site vitrine professionnel de la SARL BACHELET P M : vente d’électroménager, image et son, livraison, installation, dépannage et réparation.

## Développement

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Le site est construit avec React, TypeScript, Vinext et Tailwind CSS.
